Acceso a GitHub

Instalar y usar en 4 pasos

  1. Mira qué trae el repo

    Lista las skills de skills-portables sin instalar nada.

    npx skills add StefanoCoronado/skills-portables --list
    1 min

  2. Instala la skill

    Con --skill eliges una: peso-landing o antes-de-instalar. El instalador escanea la skill y muestra el nivel de riesgo: anótalo antes de usarla.

    npx skills add StefanoCoronado/skills-portables --skill peso-landing
    2 min

  3. Comprueba que la ve

    En Claude Code escribe /skills. Si no sale, corre /reload-skills o reinicia Claude Code.

    1 min

  4. Invócala por su nombre

    Claude Code: /peso-landing ./mi-landing. Sin agente, con Node 18 o superior: node ruta-de-la-skill/scripts/auditar.mjs ./mi-landing, con la ruta donde quedó instalada.

    2 min

Tiempos estimados, sin cronometrar. Lo que no he probado de este flujo está en la sección «Qué está probado».

Qué está probado, y qué no

Probado

Los scripts con Node en Windows: auditar.mjs dio 85/100 el 09/11. npx skills add --list encuentra las dos skills (11/11).

Sin probar

La instalación completa con npx, el escaneo de riesgo y que Claude Code liste y ejecute la skill instalada.

Fuera de alcance

Otras herramientas, donde no afirmo que la skill funcione.

Análisis estático: que no encuentre nada no prueba que algo sea seguro. Lee el SKILL.md y los scripts antes de usarla sobre datos sensibles.

Qué encontró

Una imagen sin width y height: la página salta al cargar. Arreglo: declarar sus medidas.
Tres animaciones que mueven el ancho de un elemento: el navegador recalcula la página. Arreglo: usar transform.
Sin dominios externos, sin enlaces rotos y sin archivos .env a la vista.
Solo revisa archivos. Para medir la velocidad real en un navegador usa PageSpeed Insights.

Antes de instalar, escanea

1. Tu flujo

perfil.mjs lee tu proyecto (lenguajes, dependencias, skills, hooks y servidores MCP que ya usas) sin abrir tu .env.

2. Radiografía

radiografia.mjs revisa el plugin, skill o repo sin instalarlo: cuánto contexto ocupa, licencia y patrones de riesgo, como leer cookies del navegador o descargar y ejecutar código.

3. Veredicto

Pros, contras frente a lo que ya tienes y una recomendación: INSTALAR, PROBAR EN AISLADO o NO INSTALAR, con la evidencia citada.

Errores comunes

Revisa la instalación con npx skills add StefanoCoronado/skills-portables --list. Después corre /reload-skills o reinicia Claude Code.

Usa el nombre exacto que sale en --list. Si el repo cambió, vuelve a listar antes de instalar.

Anota el nivel y el motivo que muestre. Antes de usarla sobre datos sensibles, lee la skill entera y revisa sus scripts.

Si tienes la misma skill en la ruta de usuario y en la del proyecto, puede salir dos veces. Deja una sola copia.

Comprueba que tienes Node 18 o superior con node -v y que la ruta del script y la de la landing son correctas.
